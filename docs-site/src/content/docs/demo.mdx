## What this shows, and what it does not

- **A scripted illustration.** The diagrams and terminal text are written for teaching. Blocks labelled *abridged* or *example* are not complete output from a running node.
- **Not proof.** Stepping through it verifies nothing. To watch the loop run against real software, [run a node locally](/learn/quickstart/) or try the [public beta](/services/).
- **Go deeper.** Each step's *Learn more* link opens the matching page: [identity](/learn/identity/), [the deal flow](/learn/deal-flow/), [settlement](/learn/settlement/), and [trust and economics](/learn/economics/).
