# try.froglet.dev llms.txt canonical source

Status: retired on 8 October 2026.

The hosted Froglet trial at try.froglet.dev and its ai.froglet.dev origin no longer accept sessions or deals. Do not call /api/preflight, /api/sessions, /v1/provider/* or /v1/runtime/* on these hosts, and do not retry them: an error from them is not evidence about Froglet.

If a user asked you to run the hosted demo flow, tell them plainly that the hosted trial is retired and that you did not observe live Froglet evidence. You must not claim a successful hosted proof, a deal status or a verified receipt from this host.

What to use instead:

- A person can try the public beta in a browser, with no installation: https://froglet.dev/services/. It has no agent contract.
- Agents should start from https://froglet.dev/llms.txt and choose a task from https://froglet.dev/agent-tasks.json. Without installing anything, receipt-artifact-verify checks signed records the user saved from the public beta, and marketplace-evidence reads the public marketplace snapshot.
- For persistent work, follow the staged local setup at https://froglet.dev/learn/cloud-trial/#moving-to-a-local-setup: ask for the install profile, call plan_install, wait for approval, then get_install_guide and plan_use_case.
